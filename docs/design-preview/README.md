# LOSTLY — design previews

Rendered from the real stylesheets with mock data, so you can see the intended look before
seeding a database. These are **not** the screenshots for the report — take those from your own
running app at 1440 px and 375 px.

- `home-light.png` — home page, light theme (cream paper, forest accent, gold eyebrow)
- `home-dark.png` — the same page with the header theme toggle switched to dark
- `login.png` — split auth screen
- `dashboard.png` — student dashboard with stats, tabs and the listings table
- `admin.png` — admin dashboard: stat cards, three charts, moderation queue, audit log

Design language: warm cream canvas, deep ink text, one forest-green accent, gold for emphasis,
Georgia for display headings and a system sans for body text. Hairline borders, minimal shadows,
no decorative gradients.
